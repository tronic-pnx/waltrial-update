# Waldtrial – Updates

Hier liegen nur die fertigen Spielstände und Android-Apps von Waldtrial. Der Quellcode ist privat.

- **App installieren:** [waldtrial-0.2.0.apk](apk/waldtrial-0.2.0.apk) herunterladen und auf dem Handy öffnen (Installation aus unbekannten Quellen erlauben).
- **Updates:** Die App prüft bei jedem Start `version.json`, lädt neue Spielstände im Hintergrund und übernimmt sie beim nächsten Start. Im Menü gibt es zusätzlich „Nach Update suchen“.
- **Aktuell:** Version 0.3.3, Spielstand 8, App-Hülle 2.

Siehe [CHANGELOG.md](CHANGELOG.md).
